# Language

Default: **bilingual vi + en**. Archify renders one primary language per page, so bilingual means two files per page: `<slug>.vi.html` and `<slug>.en.html`. Do not put "Đăng nhập · Login" double labels in one diagram — double-length text breaks layouts and gates.

## Viewer chrome

`meta.locale` sets Archify's own UI strings. Archify bundles `en, zh-CN, zh-TW, es, ko, ar`; Vietnamese comes from this skill's `locales/vi.json` (486 keys, placeholders checked). Set both with:

```bash
node scripts/i18n.mjs inject <candidate.json> vi   # sets meta.locale + meta.translations
node scripts/i18n.mjs inject <candidate.en.json> en
```

Explainers are Markdown (`candidate.archify.md`): set `@meta locale=vi` / `@meta locale=en` by hand; `inject` is for JSON candidates only. The explainer schema has no `translations`, so a Vietnamese explainer keeps Archify's English chrome (buttons) — authored text is still Vietnamese.

`compile-spec.mjs` applies the locale itself; `inject` is only for a hand-authored candidate (fallback). A `i18n/translation-coverage` warning after an Archify upgrade means new keys: translate exactly those keys into `locales/vi.json` and log it in `lessons.md`.

## Authored text

1. The worker (or generator) writes `spec.vi.json`; the compiler builds the Vietnamese page.
2. A light model translates it into `spec.en.json`: only reader-facing text (`label`, `sublabel`, `title`, `subtitle`, `detail`, `note`, `text`, `items`, `tag`, `comment`, card text). IDs, enums, sources, ERD column names and code identifiers stay unchanged. Generators can translate with a dictionary (`gen-tree.mjs --dict`).
3. Verify, then compile the English spec as its own output (after the Vietnamese one finished):

```bash
node scripts/i18n.mjs check-pair spec.vi.json spec.en.json
```

Each language compiles separately, so the compiler may pick a slightly different arrangement when label widths differ — that is expected.

## Index and manifest

Manifest text fields are `{ "vi": "...", "en": "..." }`; `files` maps each language to its HTML. The generated index has a vi/en switch (remembered per viewer) and falls back to whichever file exists. Single-language runs list one key only.
